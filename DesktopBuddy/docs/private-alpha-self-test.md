# DesktopBuddy 本机 Alpha 自测清单

**开始日期：** 2026-09-21  
**建议时长：** 连续 3 个完整工作日  
**测试对象：** `/Users/harryniu/Applications/Desktop Buddy.app`

这份清单只验证当前已批准的本地核心。不要在自测期间加入情绪捕获、休息提议、
日记、对话、AI synthesis、风扇写入或新的传感器。发现问题时先记录事实，不在测试中
临时改变产品范围。

## 1. 开始前

- [ ] 在 Pet settings 打开 **Launch Desktop Buddy at login**。
- [ ] 确认 **Enable Codex allowance** 已按需要开启。
- [ ] 选择平时最常看的状态：Battery、Memory 或 Codex。
- [ ] 记录当前 Interaction mode：Quiet、Balanced 或 Lively。
- [ ] 确认猪猪可显示、隐藏、拖到四条屏幕边缘，并能调整大小。
- [ ] 打开 **Local alpha activity**，记下开始时的本地计数；不要清除旧数据，除非希望从零开始。

## 2. 第一天：生命周期与恢复

### 登录启动

- [ ] 正常重启 Mac 并登录。
- [ ] Desktop Buddy 无需手动打开即可出现。
- [ ] 菜单栏猪猪和桌面猪猪均可点击。
- [ ] 面板能够打开并再次点击关闭。
- [ ] 如果 Codex 已启用，面板显示新的更新时间，无需点击刷新按钮。

### 熄屏与睡眠

- [ ] 让屏幕正常熄灭，重新点亮后检查 Codex 更新时间是否自动更新。
- [ ] 让 Mac 完整睡眠至少 5 分钟，再唤醒并检查数据是否更新。
- [ ] 唤醒后猪猪仍在预期位置和屏幕边缘。
- [ ] 唤醒后拖动、调整大小、打开和关闭面板仍然正常。
- [ ] 没有看到多个 DesktopBuddy 或 `codex app-server` 进程长期残留。

## 3. 第二天：日常价值与克制性

- [ ] 不为测试刻意频繁打开面板，观察自己是否会自然查看状态。
- [ ] 每次主动查看时记录查看的是 Battery、Memory 还是 Codex。
- [ ] 遇到通知时，记录它是否及时、可理解并且能采取行动。
- [ ] 全屏工作时，普通气泡没有打断当前屏幕。
- [ ] 专注抑制开启时，普通气泡没有在可能专注的工作中出现。
- [ ] 手动召唤猪猪仍能覆盖隐藏状态。
- [ ] 待处理通知最多三条、重复内容会合并、过期内容会自行消失。
- [ ] 没有把“没有提醒”误判为故障；沉默可能是抑制和相关性规则的正确结果。

## 4. 第三天：稳定性与资源

- [ ] 连续运行一个完整工作日，没有崩溃、猪猪消失或面板卡死。
- [ ] 面板关闭时，Activity Monitor 中 CPU 没有持续异常占用。
- [ ] DesktopBuddy 实际内存没有持续、无上限地增长。
- [ ] 没有无用户操作的持续磁盘写入。
- [ ] 使用电池时没有明显异常耗电或频繁唤醒。
- [ ] Codex 暂时不可用时，界面诚实显示 unavailable，稍后能通过自动轮询恢复。

同机回归参考值见 `docs/performance-baseline.md`：空闲 CPU 超过单核 2%、30 秒内
内存增长超过 5 MiB、idle wake-ups 超过每秒 10 次，或出现稳态磁盘写入时应调查。
这些是调查门槛，不是对所有 Mac 的性能承诺。

## 5. 每日结束记录

每天只需填写一次：

```text
日期：
运行大约多久：
最常查看的状态：Battery / Memory / Codex / 没有查看
今天最有用的一次信息：
今天最烦或最不清楚的一次行为：
是否发生崩溃、消失、卡死或数据停滞：
如果现在删除 Desktop Buddy，我会想念什么：
其他事实：
```

出现故障时补充：

```text
发生时间：
当时正在做什么：
预期行为：
实际行为：
能否重复：总是 / 偶尔 / 仅一次
恢复方式：无需操作 / 手动刷新 / 重开面板 / 重启应用 / 重启电脑
相关截图或日志：
```

不要在记录中加入密码、聊天内容、窗口正文或其他不必要的私人信息。

## 6. 三天后的判断

满足以下条件，才认为本机 Alpha 达到当前阶段的退出标准：

- [ ] 连续几个完整工作日无阻碍性崩溃或交互故障。
- [ ] 启动、熄屏和睡眠恢复后的数据刷新可靠。
- [ ] 至少一个状态提供了可重复的日常价值，而不只是第一天的新鲜感。
- [ ] 提醒和隐藏行为总体克制，没有形成新的干扰。
- [ ] 资源使用没有越过同机回归调查门槛。
- [ ] 隐私和权限行为与界面说明一致。

如果任何一项失败，下一步应修复最常发生或影响最大的真实问题；不要用增加功能来绕过它。

外部 Alpha 分发仍等待 Apple Developer Program team、Developer ID 签名和公证。这是外部依赖，
不属于本机自测未完成项。
